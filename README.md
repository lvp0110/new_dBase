# Портал приложений

Локальная оболочка на Vite, React и TypeScript. Сначала регистрация, затем вход. После входа видны только те приложения, которые разрешены роли пользователя. Каждое приложение открывается в iframe.

Пользователи, роли и переопределённые адреса хранятся в `localStorage` браузера. Стартовые роли и адреса лежат в `src/config/catalog.ts`. Администратор может сменить адрес iframe на странице «Адреса».

## Требования

Node.js `^20.19.0` или `>=22.12.0`.

## Запуск

```bash
npm install
npm run dev
```

Адрес: http://127.0.0.1:4721

Опубликованная версия: https://lvp0110.github.io/new_dBase/

Сборка уходит на GitHub Pages при отправке в `main`. В настройках репозитория источник Pages должен быть **GitHub Actions**.

## Скрипты

- `npm run dev` — режим разработки
- `npm run build` — проверка типов и сборка
- `npm run preview` — просмотр собранной версии
- `npm run lint` — проверка oxlint
