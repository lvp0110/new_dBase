# Портал приложений

Локальная оболочка на Vite, React и TypeScript. Вход через общий auth-сервис, как в `ag_co_worker` и `ap_pl_project`. Самостоятельной регистрации нет. После входа видны только те приложения, которые разрешены роли пользователя. Каждое приложение открывается в iframe.

Роли каталога и переопределённые адреса хранятся в `localStorage` браузера. Стартовые роли и адреса лежат в `src/config/catalog.ts`. Администратор может сменить адрес iframe на странице «Адреса». Роль берётся из `role_type` ответа auth. Администратор видит все приложения. Для акустика, кадров и продаж доступ отмечает администратор у каждого пункта. Роли auth вне этого списка (`user`, `manager`, `guest`) смотрят галочку «Остальные пользователи».

## Требования

Node.js `^20.19.0` или `>=22.12.0`.

## Запуск

```bash
npm install
npm run dev
```

Адрес: http://localhost:4721

Vite проксирует `/login` и `/auth` на `http://localhost:3005`. Другой адрес: `AUTH_PROXY_TARGET` или `UPSTREAM_TARGET`.

Опубликованная версия: https://lvp0110.github.io/new_dBase/

Сборка уходит на GitHub Pages при отправке в `main`. В настройках репозитория источник Pages должен быть **GitHub Actions**.

## Скрипты

- `npm run dev` — режим разработки
- `npm run build` — проверка типов и сборка
- `npm run preview` — просмотр собранной версии
- `npm run lint` — проверка oxlint
