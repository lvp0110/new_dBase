# Портал приложений

Локальная оболочка на Vite, React и TypeScript. Вход начинается с регистрации, затем со входа. После входа видны только те старые проекты, которые разрешены роли пользователя. Каждый проект открывается в iframe.

Пользователи, роли и переопределённые адреса хранятся в `localStorage` браузера. Стартовые роли и адреса лежат в `src/config/catalog.ts`. Администратор может сменить адрес iframe на странице «Адреса».

## Запуск

```bash
cd ~/Desktop/new_dBase
npm install
npm run dev
```

Адрес: http://127.0.0.1:4721
